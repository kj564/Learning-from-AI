 15304→1. **`getWalkingSpeedModifier` returns 0.7 in MCPE (not 1.0 like Java)** — this is a deliberate MCPE tweak. Faithful port MUST use 0.7 base or all mob movement will be 1.43× too fast.

 15353→### F. Stage summary (one paragraph)
 15354→
 15355→The MCPE 2013 mob system has a clean 5-class hierarchy: `Entity` → `Mob` (base, AI driver + physics + damage + despawn + network sync) → `PathfinderMob` (wander AI + path-following + flee) → `AgableMob` (baby/adult age progression) → `Animal` (grass/brightness spawn rules + 12-sec ambient sounds + 3-sec flee-on-hurt + no despawn + no breeding AI — all breeding/love/food-following code is commented out). Chicken is a leaf class with wing-flap dynamics (flapSpeed lerps ±0.3/tick, flapping decays ×0.9/tick, flap phase advances by flapping*2/tick), slow-fall (yd *= 0.6 when descending), 4 HP, 0.3×0.7 size, drops 0-2 feathers + 1 raw chicken (no cooked-on-fire), no fall damage, no egg laying (commented out), and a 6-bone ChickenModel (head + beak + wattle + body + 2 legs + 2 wings) with horizontal body (90° tilt) and alternating leg-swing (`cos(time*0.6662)*1.4*r`). MobSpawner has 3 categories (monster cap 20, creature cap 15, waterCreature cap 10), MIN_SPAWN_DISTANCE = 24 blocks from any player AND world spawn, 3 outer × 4 inner spawn attempts per chunk per tick, monster per-type cap of `(1.5*weight*20)/defaultTotalEnemyWeight`, and `postProcessSpawnMobs` (world-gen) which spawns 8% of creatures per iteration with 4 attempts per mob and jitter ±5 blocks. Baby chance is 50% per spawn with a deterministic RNG seed of 98495119L, baby age = -24000 ticks (20 minutes to grow up). Faithful port must replicate the 0.7 walking-speed modifier (NOT 1.0 like Java), the 0.42 jump velocity, the 0.08 / 0.80 / 0.50 friction branches in travel(), the exact wing-flap formula, the 24-block MIN_SPAWN_DISTANCE, the 98495119L baby RNG seed, and all the commented-out features (egg-laying, cooked drops, breeding, spider-jockey, bed-enemies, mob armor) should remain disabled to match the 2013 source.
