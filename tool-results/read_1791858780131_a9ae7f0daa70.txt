   240→  3739→    if (destroySpeed < 0) return 0;                          // indestructible
   241→  3740→    if (!player->canDestroy(this)) return 1 / destroySpeed / 100.0f;

   246→  3745→**Break speed formula — EXACT:**
   247→  3746→- If `destroySpeed < 0` (e.g. bedrock, invisible_bedrock) → return 0 (no progress, can't break).
   248→  3747→- If player `canDestroy` returns false (material isn't always-destroyable and tool's `canDestroySpecial` returns false) → return `1 / destroySpeed / 100.0f` — extremely slow (penalty).
   249→  3748→- Otherwise → return `(player->getDestroySpeed(this) / destroySpeed) / 30.0f`.
