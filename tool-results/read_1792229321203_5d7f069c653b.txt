  3052→- Block array: `blocks[(x << 11) | (z << 7) | y]` — X is the highest bits (bits 11–14, range 0..15), Z is the middle bits (bits 7–10, range 0..15), Y is the lowest bits (bits 0–6, range 0..127). Total: 15 bits = 32768 entries.

  3055→
  3056→`setTile` flow:
  3057→1. Read old block at `(x,y,z)`. If unchanged, return false (no-op).
  3058→2. Write new tile byte (`tile & 0xff`).
  3059→3. If old tile != 0: call `oldTile->onRemove(level, worldX, y, worldZ)`.
  3060→4. Reset block-data nibble to 0 (`data.set(x,y,z,0)`).
  3061→5. Recompute heightmap: if new tile blocks light and is at/above old heightmap, walk down from `y+1` to find new topmost light-blocker. If new tile doesn't block light and was placed at the old heightmap top, walk down from `y`.
  3062→6. Queue sky+block light updates at the world-coord position.
  3063→7. Run `lightGaps(x,z)` — propagate light across column boundaries (notify ±1 chunk neighbours of light column changes).
  3064→8. If new tile != 0 and not client-side: call `newTile->onPlace(level, worldX, y, worldZ)`.
  3065→9. Mark chunk `unsaved = true` and set the bit for the y>>4 sub-region in `updateMap`.
