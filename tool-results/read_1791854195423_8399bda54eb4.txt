   501→## 2.5 world/level/chunk/LevelChunk.h / .cpp
   502→- Class `LevelChunk`. Constants: `ChunkBlockCount = CHUNK_BLOCK_COUNT (32768)`,
   503→  `ChunkSize`, `UpdateMapBitShift = 4` (16 sub-columns per chunk column for update map).
   504→- Ctor: `LevelChunk(Level*, int x, int z)` or `(Level*, unsigned char* blocks, x, z)`.
   505→- Storage:
   506→  - `unsigned char* blocks` (32768 bytes, indexed `x<<11 | z<<7 | y`).
   507→  - `DataLayer data, skyLight, blockLight` (4-bit nibble arrays, packed 16384 bytes).
   508→  - `char heightmap[256]`.

   511→    lastSaveHadEntities; long lastSaveTime`.
   512→  - `const int x, z, xt, zt` (xt=x*16, zt=z*16).
   513→  - `std::vector<Entity*> entityBlocks[128/16=8]` (8 vertical 16-block slices).
   514→  - `TEMap tileEntities` (`std::map<TilePos,TileEntity*>`).
   515→- API: `getTile/setTile/setTileRaw/setTileAndData(x,y,z,val)`, `getData/setData`,
   516→  `getBlocksAndData/setBlocksAndData`, `getBrightness(LightLayer&,x,y,z)`,
