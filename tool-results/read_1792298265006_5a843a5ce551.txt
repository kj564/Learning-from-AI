    34→Stage Summary:
    35→- `client/` is a single-App, single-window fixed-timestep loop (20 tps via `Timer`,
    36→  max 10 ticks/update). `Minecraft` is the orchestrator, owns: `Options`, `Timer`,
    37→  `LevelRenderer`, `GameRenderer`, `ParticleEngine`, `SoundEngine`, `GameMode`,
    38→  `Textures`, `Font`, `Gui`, `ScreenChooser`, `IRakNetInstance`, `MouseHandler`,
    39→  `IInputHolder`, `User`, `Level*`, `LocalPlayer*`, `Mob* cameraTargetPlayer`,
    40→  `Screen*`, `HitResult`.
    41→- Two parallel UI trees share `client/gui`: (a) the in-game HUD `Gui` (hearts,
    42→  bubbles, hotbar, chat, crosshair/destroy-progress ring, item-name overlay,
    43→  sleep fade, vignette) and (b) the screen stack (`Screen` → concrete screens →
    44→  `Button`/`ImageButton`/`NinePatch`/`InventoryPane`/`ItemPane`/`ScrolledSelectionList`/
    45→  `RolledSelectionList{H,V}`/`OptionsPane`/`Slider`/`TextBox` widgets).
    46→- `Screen` lifecycle: `init(Minecraft*, w, h)` → `init()` → `setupPositions()`;
    47→  `updateEvents()` polls Mouse/Keyboard/TextChar queues and dispatches to
    48→  `mouseClicked/mouseReleased/keyPressed/keyboardNewChar`. `Screen::mouseClicked`
    49→  hit-tests every `buttons` entry via `Button::clicked()` (axis-aligned rect inside
    50→  check), pressed-state cached in `clickedButton`; release fires
    51→  `buttonClicked(button)` + `soundEngine->playUI("random.click")` only if release
    52→  is still inside the same button (touch-style press-and-release contract).
    53→  Tab-buttons (`tabButtons`) implement keyboard navigation with
    54→  `keyMenuNext/Previous/Ok`.
    55→- `Button` states: `active` (greyed out), `hovered`/`selected` (drives `yImage`
    56→  ∈ {0 inactive, 1 normal, 2 hover}); 3 subtypes: default (gui.png 200×24
    57→  slice), `Touch::TButton` (touchgui.png 66×26), `Touch::THeader` (panel header).
    58→  `BlankButton` = invisible click target used by FurnaceScreen/ArmorScreen slots.
    59→- `NinePatch` (`NinePatchDescription` + `NinePatchLayer` + `NinePatchFactory`)
    60→  is the stretchable panel primitive: 3×3 quads cached in `quads[9]`,
    61→  `exclude(int)` lets screens omit corners/edges, used as the visual backing
    62→  for slot frames, pane backgrounds, and the crafting button.
    63→- `Gui` (HUD) main entry: `render(a, mouseFree, xMouse, yMouse)` ordered:
    64→  progress indicator (touch feedback ring or crosshair), hearts/bubbles,
    65→  sleep fade, toolbar (`renderToolBar`), chat messages, selected-item name
    66→  overlay, optional debug info. Slot count is `_numSlots` (touch: 6–9,
    67→  Xperia/non-touch: `Inventory::MAX_SELECTION_SIZE` = 9 incl. the “…” slot).
    68→- `Minecraft::update()` order each frame: `timer.advanceTime()` →
    69→  `raknetInstance->runEvents(netCallback)` → for each tick `tick(i, max)`:
    70→  `gameMode->tick()`, `commandServer->tick()`, `tickInput()`, `gui.tick()`,
    71→  `gameRenderer->tick`, `levelRenderer->tick`, `level->tickEntities`,
    72→  `level->tick`, `level->animateTick`, `textures->tick`, `particleEngine->tick`,
    73→  `screen->tick`. Then `gameMode->render(a)`, `soundEngine->update(player, a)`,
    74→  `gameRenderer->render(a)`.
    75→- `Minecraft::tickInput()`: if a `screen` exists and `!screen->passEvents`,
    76→  dispatch all input to it and bail; otherwise poll mouse wheel for hotbar
    77→  scroll, mouse-down for `gui.handleClick`, keyboard for `player->setKey` and
    78→  `gui.handleKeyPressed`, then `inputHolder->getBuildInput()->tickBuild`
    79→  drives `handleBuildAction` (remove/build/attack/interact → `gameMode->*`
    80→  + raknet packet mirror).
    81→- Player hierarchy: `Entity` (x,y,z, xOld/yOld/zOld, xd/yd/zd, yRot/xRot,
    82→  AABB `bb`, walkDist, onGround, fallDistance, etc.) → `Mob` (health,
    83→  hurtTime, walk anim, `entityData:SynchedEntityData`, `aimDirection`,
    84→  MoveControl/JumpControl/PathNavigation/GoalSelector, `aiStep`,
    85→  `travel`, `baseTick`, `superTick`) → `Player` (MAX_HEALTH=20,
    86→  `Inventory* inventory`, `Abilities`, `SimpleFoodData`, armor[4],
    87→  `useItem`+`useItemDuration`, bedPosition + sleepCounter, `containerMenu`,
    88→  `owner:RakNetGUID`, `name`, `dimension`, `score`, `oBob/bob`; defines
    89→  sleep/use-item flow) → `LocalPlayer` (binds `IMoveInput* input`,
    90→  per-frame `MovePlayerPacket` + `PlayerEquipmentPacket` + `PlayerArmorEquipmentPacket`,
    91→  autoJump, `calculateFlight` for `options.isFlying`, opens Chest/Furnace/
    92→  Workbench/Stonecutter/InBed/TextEdit screens, owns `_init`/`reset`) and
    93→  `RemotePlayer` (syncs item-use via `SharedFlagsInformation::FLAG_USINGITEM`).
    94→- `GameMode` is the abstract policy: `startDestroyBlock/continueDestroyBlock/
    95→  stopDestroyBlock/destroyBlock`, `useItem/useItemOn`, `attack/interact`,
    96→  `createPlayer/initPlayer/adjustPlayer/initAbilities`, `canHurtPlayer`,
    97→  `isCreativeType/isSurvivalType`, `tick/render(a)` (publishes
    98→  `destroyProgress` to `gui` and `levelRenderer`). Subclasses:
    99→  `SurvivalMode` (progress-based break, `destroyDelay`, `initAbilities`
   100→  = no fly/no build/no invuln, `canHurtPlayer=true`), `CreativeMode`
   101→  (instant break with `DestructionTickDelay=10` repeat, `instabuild`,
   102→  `mayfly`, `invulnerable`, restores aux on `releaseUsingItem`), and
   103→  `CreatorMode` (Raspberry Pi only — wraps a `Creator`/`ICreator` event log).
   104→- `ScreenChooser` enum `ScreenId` {NONE, STARTMENU, JOINGAME, PAUSE,
   105→  PAUSEPREV, SELECTWORLD, BLOCKSELECTION} with parallel Touch/non-Touch
   106→  instantiations. `Minecraft::pauseGame` / `leaveGame` / level-generated
   107→  callbacks route through it.
   108→- Renderer layer: `GameRenderer` (`render(a)` does mouse→player turn,
   109→  `renderLevel(a)` (clear, `setupCamera`, frustum cull, dirty chunk resort,
   110→  sky/clouds, terrain, entities, particles, item-in-hand, then `gui.render`
   111→  via `setupGuiScreen`), `pick(a)` fills `mc->hitResult`); `LevelRenderer`
   112→  (`Chunk`-based, owns dirty-chunk queue, `MAX_VISIBLE_REBUILDS_PER_FRAME=3`,
   113→  `MAX_INVISIBLE_REBUILDS_PER_FRAME=1`, `CHUNK_SIZE` const,
   114→  `RenderList renderList`, implements `LevelListener`); `Tesselator` &
   115→  `Textures` are singleton-ish resources; `EntityRenderDispatcher` +
   116→  `TileEntityRenderDispatcher` route mob/tile-entity rendering; culling
   117→  via `FrustumCuller`/`AllowAllCuller`.
   118→- Sound: `SoundEngine` wraps a `SoundSystem` (SL on Android ≥ API23, AL on
   119→  iOS, stub elsewhere), holds a `SoundRepository` keyed by name (e.g.
   120→  `"step.stone"`, `"mob.sheep"`, `"random.click"`), `play(name,x,y,z,v,p)`
   121→  applies distance attenuation (`SOUND_DISTANCE=16`, `_invMaxDistance`),
   122→  `playUI` ignores 3D position. `update(player, a)` updates listener pos/angle.
   123→- Particles: `ParticleEngine` stores `ParticleList particles[4]` indexed by
   124→  texture (`MISC_TEXTURE/TERRAIN_TEXTURE/ITEM_TEXTURE/ENTITY_PARTICLE_TEXTURE`),
   125→  `add(Particle*)`, `tick()`, `render(player,a)`/`renderLit(player,a)`,
   126→  `destroy(x,y,z)` (spawns 27 `TerrainParticle`s), `crack(x,y,z,face)`.
   127→  `Particle` extends `Entity` with `age/lifetime/size/gravity/rCol/gCol/bCol`
   128→  and a `render(Tesselator&, float a, …)`. Subclasses in `client/particle/`:
   129→  `SplashParticle`, `TerrainParticle`, `BubbleParticle`, `ExplodeParticle`,
   130→  `HugeExplosionParticle`, `HugeExplosionSeedParticle`, `SmokeParticle`,
   131→  `FlameParticle`, `LavaParticle`, `RedDustParticle`, `CritParticle2`,
   132→  `BreakingItemParticle`, `TakeAnimationParticle`.
   133→- Models: `Model` (vector of `ModelPart*`, `texWidth=64`, `texHeight=32`,
   134→  `riding`, `attackTime`, `young`, `render/prepareMobModel/setupAnim`)
   135→  → `HumanoidModel` (head, body, arm0/1, leg0/1, sneaking, bowAndArrow),
   136→  `QuadrupedModel`, `SheepModel`, `SheepFurModel`, `CowModel`, `PigModel`,
   137→  `ChickenModel`, `SpiderModel`, `CreeperModel`, `SkeletonModel`,
   138→  `ZombieModel`, `SignModel`, `ChestModel`. `geom/` provides `ModelPart`,
   139→  `Cube`, `Polygon`, `Vertex`.

  1428→# 8. Level chunk storage & tick flow summary
  1429→
  1430→## 8.1 Chunk storage layout
  1431→
  1432→- World is a 16×16 grid of chunks = 256×256 columns horizontally, height 128
  1433→  (`LEVEL_HEIGHT=128`, `CHUNK_CACHE_WIDTH=16`, `CHUNK_WIDTH=16`).
  1434→- Each `LevelChunk` (16×16×128 = 32768 blocks) stores:
  1435→  - `unsigned char* blocks` — 32768 bytes, one byte per block (id 0..255),
  1436→    indexed `x<<11 | z<<7 | y` (i.e. y is the lowest 7 bits because height=128
  1437→    fits in 7 bits).
  1438→  - `DataLayer data` — 4-bit per block (16384 bytes), block data / aux value.
  1439→  - `DataLayer skyLight` — 4-bit per block, sky light (0..15).
  1440→  - `DataLayer blockLight` — 4-bit per block, emitted light (0..15).
  1441→  - `char heightmap[256]` — per-column highest non-air block (for sky-light
  1442→    propagation).
  1443→  - `unsigned char updateMap[256]` — per-column dirty-flag (16 sub-columns of
  1444→    8 blocks each, `UpdateMapBitShift=4`).
  1445→  - `int minHeight` — lowest modified block (for save-band optimization).
  1446→  - `std::vector<Entity*> entityBlocks[8]` — entities bucketed by 16-block-tall
  1447→    y-slice (8 slices × 16 blocks = 128).
  1448→  - `TEMap tileEntities` — `std::map<TilePos, TileEntity*>` of tile entities in
  1449→    this chunk.
  1450→  - Flags: `loaded, unsaved, dontSave, createdFromSave, lastSaveHadEntities,
  1451→    terrainPopulated; long lastSaveTime`.
  1452→
  1453→## 8.2 Chunk storage hierarchy (read path)
  1454→
  1455→```
  1456→Level
  1457→  └── ChunkSource* _chunkSource           (Level::createChunkSource returns:)
  1458→        new ChunkCache(this, chunkStorage, dimension->createRandomLevelSource())
  1459→                                 ↑                ↑
  1460→                                 │                └── RandomLevelSource
  1461→                                 │                    (terrain generator with
  1462→                                 │                     PerlinNoise, caves,
  1463→                                 │                     ores, trees, flowers)
  1464→                                 │
  1465→                                 └── ChunkStorage* chunkStorage
  1466→                                       (levelStorage->createChunkStorage(dimension))
  1467→                                       implementations:
  1468→                                       - MemoryChunkStorage (RAM only, demo)
  1469→                                       - ExternalFileLevelStorage (region files:
  1470→                                         RegionFile packs 1024 chunks per file)
  1471→```
  1472→
  1473→`ChunkSource` interface: `hasChunk(x,z)`, `getChunk(x,z)→LevelChunk*`,
  1474→`create(x,z)`, `postProcess(parent,x,z)`, `tick()→bool`, `shouldSave()→bool`,
  1475→`saveAll(onlyUnsaved)`, `getMobsAt(cat,x,y,z)→Biome::MobList`,
  1476→`gatherStats()→string`.
  1477→
  1478→`ChunkCache` is the LRU/cache layer that wraps `RandomLevelSource` (terrain
  1479→gen) + `ChunkStorage` (persistence). On a `getChunk(x,z)` cache miss it
  1480→asks `ChunkStorage::load(level,x,z)` (returns NULL if not saved) and
  1481→falls back to `RandomLevelSource::getChunk(x,z)` to generate, then stores
  1482→in cache and marks for save.

  1484→## 8.3 Level tick flow (per game tick, called from Minecraft::tick)
  1485→
  1486→`Minecraft::tick(i, max)` calls in order (from Task 3-a notes):
  1487→1. `gameMode->tick()`
  1488→2. `commandServer->tick()`
  1489→3. `tickInput()`
  1490→4. `gui->tick()`
  1491→5. `gameRenderer->tick()` (interpolation prep)
  1492→6. `levelRenderer->tick()` (chunk dirty queue)
  1493→7. `level->tickEntities()`     ← entity + tile-entity update
  1494→8. `level->tick()`             ← world tick (mobs, chunks, time, tiles)
  1495→9. `level->animateTick(xt,yt,zt)`  ← random block particle effects
  1496→10. `textures->tick()`
  1497→11. `particleEngine->tick()`
  1498→12. `screen->tick()`
  1499→
  1500→### `Level::tickEntities()` (Level.cpp:1330-1468)
  1501→1. For each `Entity* e : entities`:
  1502→   - if `!e->removed`: `tick(e)` → `tick(e, true)`:
  1503→     - save xOld/yOld/zOld, yRotO/xRotO
  1504→     - if `e->inChunk && hasChunksAround(e, 32)`: `e->tick()` (virtual —
  1505→       Mob::tick → aiStep → travel + updateAi + baseTick)
  1506→     - NaN sanity checks (x ≠ x ⇒ restore)
  1507→     - recompute chunk membership if entity moved chunks; if `hasChunk(xcn,zcn)`:
  1508→       `addEntity(e)` into new chunk's `entityBlocks[ycn]`; else `inChunk=false`
  1509→   - if `e->removed && (!isPlayer || reallyRemoveIfPlayer)`:
  1510→     remove from chunk, erase from `entities` + `entityIdLookup`,
  1511→     `entityRemoved(e)`, queue for `delete` (players deferred via
  1512→     `_pendingPlayerRemovals` with 16-tick grace).
  1513→2. Walk `_pendingPlayerRemovals` decrementing ticks; `delete` when 0.
  1514→3. `updatingTileEntities = true`:
  1515→   - For each `TileEntity* te : tileEntities`:
  1516→     - if `!te->isRemoved() && te->level != NULL && hasChunkAt(x,y,z)`:
  1517→       `te->tick()` (furnace cooking, sign nothing, chest nothing, nether
  1518→       reactor pattern check)
  1519→     - if `te->isRemoved()`: erase from `tileEntities`, remove from chunk's
  1520→       TEMap, `delete te`.
  1521→4. `updatingTileEntities = false`.
  1522→5. Process `pendingTileEntities`: dedupe against `tileEntities`, attach to
  1523→   `LevelChunk::setTileEntity(x&15, y, z&15, e)`, `sendTileUpdated(x,y,z)`.
  1524→
  1525→### `Level::tick()` (Level.cpp:184-254)
  1526→1. Mob spawning: if `!isClientSide && levelData.getSpawnMobs()` every
  1527→   `MobSpawnInterval=2` ticks call `MobSpawner::tick(this, _spawnEnemies &&
  1528→   difficulty>PEACEFUL, _spawnFriendlies && (time % 400) < 2)`.
  1529→2. `_chunkSource->tick()` (process chunk gen/save queue).
  1530→3. `updateSkyDarken()` (recompute `skyDarken` from time-of-day).
  1531→4. Time advance:
  1532→   - If `_nightMode`: snap/accelerate time toward `MIDDLE_OF_NIGHT_TIME=12000`,
  1533→     broadcast `SetTimePacket`.
  1534→   - Else: `time = levelData.getTime() + 1; levelData.setTime(time)`; broadcast
  1535→     `SetTimePacket` every 256 ticks.
  1536→5. `tickPendingTicks(false)` — run up to `MAX_TICK_TILES_PER_TICK=100` scheduled
  1537→   tile ticks (`_tickNextTickSet` sorted by delay); each calls
  1538→   `Tile::tiles[id]->tick(this, x, y, z, &random)` if the tile id at the
  1539→   position still matches and surrounding 8-chunk radius is loaded.
  1540→6. `tickTiles()` — random-block-tick loop:
  1541→   - Build `_chunksToPoll` set: for each player, poll the 49 surrounding
  1542→     chunks (`pollChunkOffsets[]` spiral out to ±4 chunks).
  1543→   - For each polled chunk, run 20 random ticks (`_randValue = _randValue*3 +
  1544→     _addend` LCG; extract `x = val&15`, `z = (val>>8)&15`, `y = (val>>16)&127`).
  1545→     If `Tile::shouldTick[id]` is true, call `Tile::tiles[id]->tick(this,
  1546→     x+xo, y, z+zo, &random)`.
  1547→7. For each `Entity* e : entities` with dirty `SynchedEntityData`, broadcast
  1548→   `SetEntityDataPacket(e->entityId, *data)` to all clients.
  1549→
  1550→### `Level::tick(Entity* e, bool actual)` (Level.cpp:1500-1556)
  1551→- Bail out if surrounding 32-block chunks aren't loaded.
  1552→- `e->xOld=e->x; e->yOld=e->y; e->zOld=e->z; e->yRotO=e->yRot; e->xRotO=e->xRot;`
  1553→- If `actual && e->inChunk`: `e->tick()` (virtual dispatch).
  1554→- NaN sanity restore.
  1555→- Recompute chunk membership:
  1556→  - `xcn = floor(e->x/16); ycn = floor(e->y/16); zcn = floor(e->z/16);`
  1557→  - If chunk changed and old chunk loaded: `getChunk(old)->removeEntity(e,
  1558→    old_ycn)`.
  1559→  - If new chunk loaded: `e->inChunk=true; getChunk(new)->addEntity(e);`
  1560→    else `e->inChunk=false`.
  1561→
  1562→### `Level::tickTiles()` (Level.cpp:257-337)
  1563→- See step 6 above. Spawns 20 random block ticks per polled chunk per game
  1564→  tick (so up to ~980 tile ticks per tick across 49 chunks). Limited to tiles
  1565→  whose `Tile::shouldTick[id]` flag is set (crops, saplings, leaves, grass,
  1566→  mushrooms, farmland, liquid, fire, etc.). The LCG `_randValue = _randValue
  1567→  * 3 + _addend` (seed 42184323, addend 1013904223 — java.util.Random
  1568→  constants) is the same used by Java edition's `Random` class.
  1569→
  1570→### `Level::addToTickNextTick(x,y,z,tileId,tickDelay)` (Level.cpp:1307-1328)
  1571→- Schedule a tile tick: insert `TickNextTickData(x,y,z,tileId)` with
  1572→  `delay = tickDelay + levelData.getTime()` into `_tickNextTickSet` (a
  1573→  `std::set<TickNextTickData>` ordered by delay then by position).
  1574→- If `instaTick`: run immediately instead of queuing.
  1575→
  1576→### `Level::getCubes(source, AABB)` (Level.cpp:1119-1161)
  1577→- The collision query: scan every block in the AABB's integer extent, look up
  1578→  `Tile::tiles[getTile(x,y,z)]`, and call `tile->addAABBs(this, x, y, z, box,
  1579→  boxes)` to append the tile's collision boxes. Returns a `vector<AABB>&`
  1580→  reused across calls (cleared at start). Used by `Entity::move()` and
  1581→  `Entity::isFree()` for clip-and-slide.
  1582→
  1583→### `Level::clip(Vec3 a, Vec3 b, liquid, solidOnly)` (Level.cpp:849-954)
  1584→- The block ray-pick used by `Minecraft::pick(a)`: DDA voxel traversal (≤200
  1585→  steps) from `a` to `b`. At each crossed voxel, look up the tile; if it
  1586→  `mayPick(data, liquid)`, call `Tile::tiles[t]->clip(this, x, y, z, a, b)`
  1587→  to do the exact ray-AABB intersection, and return the closest hit as a
  1588→  `HitResult(type=TILE, x,y,z, face, pos)`.
  1589→- `solidOnly=true` skips tiles with NULL collision AABB (liquids, fire, etc.).
  1590→- `liquid=true` allows picking liquid tiles (for bucket fill).
  1591→
  1592→### `Level::getRawBrightness(x,y,z[,propagate])` (Level.cpp:725-761)
  1593→- Special cases: stoneSlabHalf & farmland take the max of neighbor brightness
  1594→  (so light passes through gaps).
  1595→- If `y >= DEPTH`: return `MAX_BRIGHTNESS - skyDarken` (clamped to 0).
  1596→- Else: `chunk->getRawBrightness(x, y, z, skyDarken)` which combines skyLight
  1597→  and blockLight (max), reduced by `skyDarken` for night.
  1598→- `getBrightness(x,y,z)→float` applies `dimension->brightnessRamp[raw]` to
  1599→  convert the 0..15 integer to a 0..1 float with gamma curve.
  1600→

  1602→- BFS light propagation: enqueue boundary blocks, propagate light via
  1603→  `_lightUpdates` queue (`LightUpdate{layer, x, y, z, brightness}`), set
  1604→  `chunk->setBrightness(layer, ...)`, recurse. `join=true` merges with an

  1625→### `Level::explode(source, x, y, z, r[, fire])` (Level.cpp:1658+)
