  9626→{

  9628→

  9630→    for (unsigned int i = 0; i < buttons.size(); ++i) {
  9631→        Button* button = buttons[i];

  9633→            buttonClicked(button);     // dispatch to subclass
  9634→            minecraft->soundEngine->playUI("random.click", 1, 1);

  9641→
  9642→**Mouse click sequence:**
  9643→1. On `mouseClicked` (left button down): hit-test all buttons. The first button whose bounds contain the cursor has `_currentlyDown = true` set (becomes "pressed") and is recorded as `clickedButton`.

  9645→3. **Note:** if multiple buttons overlap, only the LAST pressed one (because `clickedButton` is overwritten) wins the click.
