  4561→### Summary of break timing per game mode
  4562→
  4563→**Survival:** 
  4564→- First hit (left-click press): if `getDestroyProgress(player) >= 1`, instant break; else just call `tile->attack`.
  4565→- Hold left-click: per-tick accumulate `destroyProgress += tile->getDestroyProgress(player)`. Play step sound every 4 ticks. Break when `destroyProgress >= 1`.
  4566→- After break: 5-tick `destroyDelay` cooldown (`destroyDelay = 5` in continueDestroyBlock).
  4567→- Look away or release: reset progress to 0.
  4568→
  4569→**Time-to-break** ≈ `30 * tile.destroySpeed / tool.getDestroySpeed(tile)` ticks ≈ `1.5 * destroySpeed / toolSpeed` seconds (at 20 TPS).
  4570→
  4571→For example:
  4572→- Hand (speed 1) on stone (destroySpeed 1.5): `30 * 1.5 / 1 = 45 ticks = 2.25s`.
  4573→- Wooden pickaxe (speed 2 on stone) on stone: `30 * 1.5 / 2 = 22.5 ticks ≈ 1.13s`.
  4574→- Diamond pickaxe (speed 4 on stone, matching material) on stone: `30 * 1.5 / 4 = 11.25 ticks ≈ 0.56s`.
  4575→- Hand on obsidian (destroySpeed 10): bare hand `canDestroy(obsidian)` returns false (obsidian material = stone, `notAlwaysDestroyable`; bare hand `canDestroySpecial` returns false). So formula = `1 / 10 / 100 = 0.001` per tick → 1000 ticks = 50s to break obsidian with bare hand.
  4576→- Diamond pickaxe (level 3) on obsidian (speed 4): `30 * 10 / 4 = 75 ticks = 3.75s`.
  4577→- Bedrock (destroySpeed = -1): `getDestroyProgress` returns 0 → never breaks.
  4578→
  4579→**Creative:**
  4580→- First hit: instant break + set `destroyDelay = 10`.
  4581→- Hold: every 10 ticks, auto-break the block under the crosshair (= 2 blocks/sec).
