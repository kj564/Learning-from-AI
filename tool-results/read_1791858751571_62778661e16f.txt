  3736→### Tile::getDestroyProgress(player) — VERIFIED (Tile.cpp:391–395)
  3737→```cpp
  3738→float Tile::getDestroyProgress(Player* player) {
  3739→    if (destroySpeed < 0) return 0;                          // indestructible
  3740→    if (!player->canDestroy(this)) return 1 / destroySpeed / 100.0f;
  3741→    return (player->getDestroySpeed(this) / destroySpeed) / 30.0f;
  3742→}
  3743→```
  3744→
  3745→**Break speed formula — EXACT:**
  3746→- If `destroySpeed < 0` (e.g. bedrock, invisible_bedrock) → return 0 (no progress, can't break).
  3747→- If player `canDestroy` returns false (material isn't always-destroyable and tool's `canDestroySpecial` returns false) → return `1 / destroySpeed / 100.0f` — extremely slow (penalty).
  3748→- Otherwise → return `(player->getDestroySpeed(this) / destroySpeed) / 30.0f`.
  3749→
  3750→`player->getDestroySpeed(tile)` (Player.cpp:556–561):
  3751→```cpp

  3757→}
  3758→```
  3759→Which delegates to `Inventory::getDestroySpeed` (Inventory.cpp:316–323):
  3760→```cpp

  3762→    ItemInstance* item = getSelected();
  3763→    if (item && item->id >= 256) {
  3764→        return Item::items[item->id]->getDestroySpeed(NULL, tile);
  3765→    }
  3766→    return 1.0f;
  3767→}
  3768→```
  3769→And `Item::getDestroySpeed(itemInstance, tile)` default returns `1` (Item.h:267–269). Subclasses (`HatchetItem`, `PickaxeItem`, `ShovelItem`, `ShearsItem`, `WeaponItem`) override to return `speed` (tier-dependent) if the tile matches their material, else fall back to `super::getDestroySpeed` (=1).
  3770→
  3771→`player->canDestroy(tile)` (Player.cpp:563–565) → `Inventory::canDestroy(tile)` (Inventory.cpp:307–314):
  3772→```cpp
  3773→bool Inventory::canDestroy(Tile* tile) {
  3774→    if (tile->material->isAlwaysDestroyable()) return true;
  3775→    ItemInstance* item = getSelected();
  3776→    if (item != NULL) return item->canDestroySpecial(tile);
  3777→    return false;
  3778→}
  3779→```
  3780→`Material::isAlwaysDestroyable()` returns `_isAlwaysDestroyable` (default true). Materials flagged `notAlwaysDestroyable()`: `stone`, `metal`, `topSnow`, `snow`. For those, player must have a tool whose `canDestroySpecial(tile)` returns true (e.g. pickaxe for stone/metal, shovel for snow).
  3781→
  3782→**Summary:** the per-tick `destroyProgress` increment is `(toolSpeed / tileDestroySpeed) / 30`. When `destroyProgress >= 1` (accumulated by SurvivalMode::continueDestroyBlock — see Entry 12), the block breaks. So time-to-break (in ticks) ≈ `30 * destroySpeed / toolSpeed` for a compatible tool.
